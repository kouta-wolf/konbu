# konbu

本アプリは、Rustを使って作成した日記 / メモ管理用のTUIアプリケーションです。
多機能なメモアプリに疲れた人に向けて、軽量かつ高速な最低限のアプリを目指しています。

## 基本方針

- 短い文章（簡単な日記やTODO）向け。長いドキュメント管理は対象外
- 保存形式はMarkdownファイル
- 編集は$EDITOR(Neovimなど)で行い、アプリにはエディタ機能は導入しない
- TODOは本文中のチェックボックスで書く(- [ ] / - [x] )

## 日記とメモ

- 日記は1日1ファイル、`daily/YYYY-MM-DD.md`。過去の日付の日記も作ることが可能
- メモは1メモ1ファイルで、`memo/<タイトル>.md`。ファイル名がそのままタイトルになる
  - ファイル名に使えない文字は`_`に置き換え。同じタイトルのメモは作れない
- どちらのファイルの先頭にもfrontmatterをつける

```
---
id: 20261109235725
type: memo
created: 2026-11-09
---
```

- 日記の画面に「その日に作ったメモ」を表示する。日記ファイル自体は書き換えない

## 画面と操作

- 左側のサイドバーにカレンダーと一覧。一覧は当日の日記と全メモの2タブで、全メモは作成日の新しい順に並ぶ
- 右側は選択中のファイルのプレビュー(read only)
- Enterでエディタを開き、エディタを閉じるとTUIに戻る
- キー操作はvim風( hjkl / Enter / n / Tab / q)で矢印キーも使える
- `$ konbu` でTUIを起動し、`konbu today`で今日の日記を直接エディタで開く

## MVPの範囲

- 含む: 今日の日記を開く / 作る、日記の一覧、ファイルを開く、カレンダーのサイドバー、その日のメモの表示、全メモ一覧、メモの新規作成
- 含まない: 全文検索、日記へのリンク追記、設定ファイル、同期の補助、cargo installでの配布、日付が切り替わる時刻の設定、削除とリネーム、IDを使ったリンク

## データの保存場所

- 環境変数 KONBU_DIRで指定する。指定しなければ~/konbu になる
- 構成は次の通り

~/konbu/
├── daily/   # 日記
└── memo/    # メモ

データはアプリのリポジトリとは別の場所に置く。同期したい場合はデータディレクトリを自分で非公開のgitリポジトリにする運用を想定している

## 開発体制

- backend（データ構造、保存、読み込み）は作者が手で書いている
- view(TUI)はAI（Claude）と協働で書き、該当するcommitにはCo-Authored-Byをつける
- 全ての変更はPRを通して反映し、進み具合はGitHub Projectsで管理している
